# Reference analysis: extract decisions, not a screenshot-shaped skin

## Collect comparable evidence

For the actual task, inspect a small set of useful screens rather than a giant
mood board: a representative normal state, one dense/exception state, one focus
or selection state, and a transition recording where movement matters. Record
source, creator, screen, release/concept status, and what is actually visible.
Use official footage or a direct creator's portfolio when possible. A promotional
render, development concept, shipped screen, and fan redesign are different evidence.

Brieuc Inisan's Expedition 33 portfolio explicitly includes battle HUD concepts
and in-engine animation work. Treat the work as evidence of authored composition
and cross-disciplinary UI production, not proof that every concept shipped.
Frostpunk 2 portfolios likewise expose selected screens and workflow stages, not
a complete reusable style specification. [D01–D04]

## Deconstruct in layers

Write short observations under these headings:

| Layer | What to inspect |
|---|---|
| Decision | What is the player deciding, and what information supports that decision? |
| Composition | Large masses, empty regions, focal point, stable edges, relationship to the world |
| Type | Role hierarchy, case, width, baseline, numeral alignment, line lengths |
| Shape | Repeated geometry; which shapes mean action, status, category, or ornament? |
| Material | Flat, printed, metallic, translucent, painterly; where detail is deliberately absent |
| State | How focus differs from selection, availability, ownership, and urgency |
| Motion | Order, direction, interruption, settling, and interaction readiness |

Estimate geometry as a fraction of the reference frame before proposing logical
UI units. Label estimates; do not claim production token values. Inspect enlarged
crops for edge treatment and the complete frame for composition. Thumbnail review
is a hierarchy diagnostic, not a test of text readability at playing distance.

## Separate observation, inference, and proposal

Example: "The action list sits on a dark irregular region" is an observation.
"The region protects contrast against changing backgrounds" is a plausible
inference. "Use a separate brush-mask texture over a native action list in Godot"
is an implementation proposal. Keep those labels distinct.

A still cannot establish easing, duration, audio, focus order, or how a panel
closes. Without inspectable motion footage, propose a motion language and identify
it as original. Do not fabricate frame-by-frame measurements from a video title.

## Translate, do not trace

Retain the useful relationship—e.g. a quiet information panel contrasted with an
expressive illustration—while creating new proportions, symbols, and artwork for
the project's world. Avoid importing ripped logos, fonts, portraits, or textures.
Do not combine several games' signature motifs merely because each is attractive.

Output a reference ledger with: source, observed principle, project adaptation,
intentional deviation, and evidence confidence. Follow with three concrete visual
rules and three examples to reject. Those rules must be testable in the hero screen.
