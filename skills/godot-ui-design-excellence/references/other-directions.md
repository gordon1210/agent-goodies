# Other modern directions: choose a grammar, not a mixture

## Expressive editorial

Use deliberate scale contrast, assertive typography, off-axis composition, graphic
cuts, and strong transitions when the game supports an expressive identity. Keep
a stable interaction skeleton beneath that energy: repeat anchor relationships,
maintain clear focus, and avoid moving the target during selection.

A header can be rotated while the detailed item comparison remains upright. A
transition may cut across the frame while the next screen is already usable.
Pattern repetition creates fluency; random rotation and unrelated type treatments
create noise. Never interpret an expressive reference as permission to make long
body text difficult to read.

The GDC listing for the Metaphor UI session is useful further viewing, but this
package did not inspect the complete talk. Do not attribute specific animation
rules, measurements, or production techniques to that session.

## Restrained tactical

Prioritize stable spatial registration, compact legible instruments, clear status
categories, and minimal competing animation. Technical-looking lines should
communicate range, grouping, or alignment rather than decorate every empty pixel.
Use a sparse accent system and unambiguous warnings. Avoid relying on tiny
all-uppercase metadata to sell sophistication.

Match information lifetime to the task: an aiming cue may be continuously updated;
a contextual prompt should appear only while relevant; important persistent state
should remain available without forcing memory. Intentional linear motion may be
correct for a timer or instrument.

## Luminous or clean futuristic

Use broad value fields, selected transparency, consistent geometry, and precise
micro-interactions. "Futuristic" need not mean everything is cyan or glowing.
Reserve emissive cues for specific interactions and maintain an opaque/high-contrast
alternative. Test the interface against a bright scene, not only black concept art.

## Historical or material-rich

Translate material identity into a few robust cues: paper edges, ink registration,
metal fixtures, engraved line work, or fabric patches. Avoid reproducing the full
physical complexity of an object around every label. A texture should survive
scaling and localization without tying functional text to a fixed image.

## Mixing rules

Combine directions only when their roles are explicit. For example, an expressive
reward screen can share type roles and symbols with a restrained combat HUD while
using a different attention budget. Do not combine three unrelated games' primary
motifs into a single busy menu.

Prove family resemblance across at least a compact HUD, a dense information screen,
and a dialog. A design that only works at one density is an illustration, not yet
an interface system. Maintain a reference ledger documenting what belongs to this
project rather than naming one source game as its permanent style definition.
