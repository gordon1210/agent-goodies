# Source register

Research reviewed on **2026-09-06**.

This package is an original synthesis, not a compilation of copied third-party skills.
Its design recipes, example worlds, timing suggestions, layouts, and token sets are
original proposals. They are not measured specifications of the named games.

Primary technical sources are official Godot and agent documentation. Game-design
sources include direct creators and first-party design/engineering articles.
Accessibility recommendations are separated from aesthetic judgments. Conference
abstracts and unwatched videos are explicitly limited rather than treated as
reviewed talks. External pages may move or change; the local link validator does
not test their current availability.

Godot 4.7 was used as a documentation reference, not a migration target. Some
reviewed pages use the mutable `stable` URL. At implementation time, check the
installed version and consult its matching documentation.

No game screenshots, licensed fonts, or third-party art are redistributed.
The machine-readable counterpart is [sources.json](../assets/sources.json).
