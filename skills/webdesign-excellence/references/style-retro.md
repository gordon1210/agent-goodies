# Style: intentional retro-futurism

**Load when:** the user explicitly selects a historical or speculative visual vocabulary.

## Design thesis

Choose one coherent era or genre and reinterpret it with current interaction quality.
A retro surface can be contemporary work, but retro itself is not evidence of
modern usability. Avoid indiscriminately mixing terminal green, chrome Y2K blobs,
90s browser windows, and arcade pixel fonts.

## Grammar to establish

Name the reference vocabulary precisely: archival terminal, early digital magazine,
space-age instrument panel, or another specific direction. Choose type, color,
shape, iconography, texture, and movement that belong to that vocabulary. Keep
normal reading text comfortable even when the display type is heavily stylized.

Technical-looking metadata must either convey real information or be clearly
non-informational artwork. Never use fabricated live system status as decoration.
Use an era-inspired frame around modern semantic controls instead of rebuilding
inaccessible controls because they look historically accurate.

## Concrete composition

For a game-related web campaign, an era-specific title and key artwork can establish
the world; follow with the actual game premise, media, requirements, and next action.
For a creative archive, use a stable index and case-study structure beneath the
period styling. Genre can frame the content without replacing it.

## Optional techniques and boundaries

A static halftone, restrained scanline image texture, chromatic material, or controlled
type animation can work. Do not stack all of them. If the concept requires glitch,
make it brief, optional, and non-essential; evaluate flashing risk rather than
assuming a small CSS effect is harmless.

**Avoid:** illegible pixel body text; fake operating-system warnings; unpredictable
cursor replacement; flashing status labels; autoplay sound; intentional broken
navigation; enormous faux desktop chrome consuming the phone viewport. Never use
a “vintage” excuse for failed contrast, keyboard access, or error handling.

## Adaptation and acceptance

Retain the vocabulary through type, palette, and one framing motif on mobile;
remove elaborate window clutter. The reduced-motion and static versions should
still be recognizably part of the same identity.

**Pass:** a reader can identify the intended visual world, use the site normally,
and distinguish decorative fiction from real interface information.
