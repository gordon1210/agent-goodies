# Page route: publications, documentation, and long-form content

**Load when:** reading, navigation, discovery, or reference lookup is the primary task.

## Choose reading versus lookup density

A publication may need an expressive opening and a calm reading column. Documentation
needs findability, examples, stable navigation, and predictable hierarchy. Do not
force either into a marketing sequence. An editorial visual identity can coexist
with a more functional reading surface without creating a new style system.

## Structure

Use a meaningful heading hierarchy, descriptive links, stable anchors, and useful
metadata. Distinguish article body, caption, quotation, code, and related content.
A table of contents should reflect actual sections rather than every small heading.
Keep long paragraphs at a deliberate measure and avoid full justification unless
the typographic context genuinely supports it.

For documentation, preserve version context and make outdated or unavailable
information explicit. Code should be selectable, readable, and horizontally contained
when necessary. Copy controls need honest clipboard success/failure feedback. Do not
make hover the only way to reveal important code or definitions.

## Navigation and discovery

Use a stable local navigation pattern and a sensible mobile version. Search results
need context and a clear empty state. A reading progress indicator is optional;
it should not compete with text or announce every scroll change. Sticky headings
and sidebars must release when the viewport is too short or zoom makes them obstructive.

Keep related links and recommendations outside the main reading flow when they
interrupt comprehension. Do not add endless automatic transitions to a reference
page that users open many times a day.

## Acceptance

Test a long article with images, lists, code, tables, citations, and several heading
levels. Check text enlargement and spacing overrides; no content should be clipped
by a fixed-height presentation. Verify anchors, keyboard navigation, search recovery,
and the small-screen table of contents.

If print or offline use is part of the brief, provide a readable representation
without pinned layers, hidden reveal content, or decorative media controls. Preserve
real attribution and external links. Do not fabricate author credentials or update dates.
