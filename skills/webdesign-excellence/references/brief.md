# Brief, reference analysis, and design contract

**Load when:** a new visual direction is needed, the reference is ambiguous, or a redesign needs scope.

## Establish the job before the aesthetic

Extract audience, their immediate task, the primary action, content hierarchy,
brand constraints, available assets, delivery surface, and implementation stack.
Separate supplied facts from assumptions. Existing production content is not
permission to rewrite business claims. A narrow component request is not a rebrand.

Ask a focused question when an unknown changes scope, brand fidelity, content
truthfulness, licensing, or a critical user flow. When taste is explicitly delegated,
make a reversible creative choice and explain it in one sentence. Unavailable imagery
is a real dependency: use a labeled placeholder or an image-independent direction,
not a fabricated claim that a media-led design is complete.

## Read references as systems

Inspect the actual page or supplied screenshot before judging its appearance.
A prompt describes intent, not proof of the result. Distinguish desktop screenshots,
mobile layouts, recordings, implementation code, and written specifications.
Never report hover, responsiveness, or accessibility as observed from a still image.

Extract five things, not a shopping list of effects:

- **Hierarchy:** what is noticed first, second, and third; why.
- **Geometry:** alignments, density, image proportions, whitespace, recurrence.
- **Type and color roles:** structural relationships rather than exact brand assets.
- **Behavior:** what a transition explains and what remains stationary.
- **Exclusions:** treatments that would undermine this particular direction.

Reference A may provide composition and B motion behavior, but do not copy both
brands into one design. Preserve original content, distinctive assets, and source
rights. Explicit recreation tasks still require honest asset provenance.

## Lock a small contract

Record the audience/action, one primary style, type roles, palette roles, shape and
spacing grammar, image direction, motion behavior, exclusions, and responsive fallback.
Choose three observable invariants such as “one left alignment spine,” “photography
carries color,” or “dense comparable rows remain comparable.” Do not substitute
adjectives such as premium, innovative, clean, or stunning for decisions.

For multi-session work, use the optional design-contract template. For a tiny task,
keep the same information in a sentence; do not create a planning bureaucracy.

## Sequence the work

Establish content and static layout. Finish a representative slice containing real
copy, a key visual, a control, and its small-screen behavior. Review before expanding
the system. Add a signature effect last, only if its static counterpart already works.
If the design is weak without the effect, revise the composition.

**Exit:** the agent can explain why this direction suits this audience, what it will
not combine, and how the experience works without premium media or motion.
