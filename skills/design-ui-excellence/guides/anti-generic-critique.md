# Anti-Generic Quality & Design Critique

Use this guide to prevent or diagnose generic, trend-stacked, AI-shaped output.

Generic design usually lacks specific decisions. The fix is not automatically more decoration.

## Pre-delivery critique

Ask:

1. **Specificity** — Could this belong to any product after changing the logo?
2. **Hierarchy** — Is the intended first, second, and third read obvious?
3. **Evidence** — Does the experience show the product or outcome, or merely describe it?
4. **Coherence** — Do typography, layout, assets, content, surfaces, and motion express one thesis?
5. **Restraint** — Does every visible element earn attention or function?
6. **Usability** — Can the audience complete the actual task?
7. **Resilience** — Does it survive mobile, zoom, long content, errors, and reduced motion?
8. **Originality** — Is it distinct without reproducing a reference's identity?

Revise any weak axis before polishing micro-details.

## Common failure patterns

### Template-shaped marketing

Symptoms:

- centered headline, generic gradient, two CTAs, floating dashboard
- repeated eyebrow, heading, paragraph, and three cards
- alternating image/text sections with no narrative purpose
- standard four-column footer copied regardless of content
- every page using the same hero and section rhythm

Repair: return to page job, audience awareness, proof, assets, and narrative. Choose forms that fit each content job.

### Cardification

Symptoms:

- every paragraph, metric, icon, and action lives in a rounded card
- nested cards create visual noise
- grouping is communicated only by containers

Repair: use whitespace, alignment, typography, dividers, shared surfaces, and fewer meaningful containers.

### Bento without information design

Symptoms:

- arbitrary spans
- empty filler cells
- uniform text blocks inside varied geometry
- hierarchy implied by tile size but unsupported by content

Repair: let content importance, media, comparison, or interaction determine the grid. Remove cells that do not carry a job.

### Trend stacking

Symptoms:

- gradients, glass, blobs, grain, oversized type, glow, pills, and scroll effects combined without a thesis
- visual effects applied to every section
- “modern” used as the only rationale

Repair: choose one direction and one signature moment. Make supporting surfaces quiet.

### Decorative trust

Symptoms:

- invented customer logos
- fabricated metrics or testimonials
- generic security badges
- fake reviews, activity, locations, coordinates, or system status

Repair: use real proof, a clearly labeled placeholder, product evidence, methodology, or an honest limitation.

### Copy-shaped decoration

Symptoms:

- vague claims that fill space
- interchangeable headlines
- excessive tiny uppercase labels
- generic AI vocabulary
- unexplained precision
- inconsistent CTA synonyms

Repair: write from audience, mechanism, evidence, and action. Delete labels that add no information.

### Asset substitution

Symptoms:

- brand represented only by a color
- recognizable product replaced with CSS shapes
- fake device/browser chrome
- mixed icon families or illustration styles
- generated assets drift between sections

Repair: source official assets, define an anchor and visual bible, or expose an honest asset gap.

### Marketing styling in product UI

Symptoms:

- giant headings and theatrical whitespace in a daily workflow
- low information density
- animated entrances on repeated actions
- operational status hidden behind decoration

Repair: prioritize scanning, stable alignment, state, feedback, and task speed.

### Motion spectacle

Symptoms:

- every element reveals on scroll
- several ambient loops compete
- hover effects stack transform, shadow, blur, and color
- repeated actions wait for animation
- no reduced-motion path

Repair: define purpose, frequency, one dominant motion idea, and a static state cue.

### Happy-path-only design

Symptoms:

- only populated success state exists
- forms have no recoverable errors
- long content breaks
- permission and unavailable states are missing
- mobile is a collapsed desktop mockup

Repair: enumerate the state and content matrix before final polish.

## Critique discipline

- Report consequential issues, not every preference.
- Group recurring symptoms by root cause.
- Explain impact on comprehension, trust, conversion, task completion, accessibility, or maintainability.
- Recommend the smallest effective fix.
- Preserve deliberate brand choices unless they create a concrete problem.
- Do not make the interface different merely to prove originality.
- Do not inflate severity because a rule has an exception.

A controlled rule break can create character when it serves the thesis. Do not force one into every artifact.
