## Synthesis choices

Several source skills contain strong stylistic preferences or exact values. This package deliberately converts those into contextual defaults instead of universal laws. It does not mandate a specific font, palette, corner radius, layout archetype, animation library, or visual trend.

The resulting hierarchy is:

1. explicit user direction
2. established project and brand constraints
3. observed user, product, and content needs
4. route-specific guidance in this skill
5. general defaults

This prevents the skill from replacing one generic AI aesthetic with another.
