# Changelog

All notable changes to Idea Workbench are documented here.

This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-17

### Added

- A context-adaptive workflow for greenfield, existing-system, and hybrid work.
- Six composable skills covering idea shaping, option exploration, design,
  review, implementation planning, and workflow routing.
- Reusable templates and quality references for every artifact-producing stage.
- Portable packaging for Codex/ChatGPT and Claude Code.
